## Quick example

```python
from pydantic_ai import Agent
from pydantic_ai_guardrails import DetectPII, DetectPromptInjection, LimitCost, RedactSecrets

agent = Agent(
    'openai:gpt-4o',
    capabilities=[
        DetectPromptInjection(sensitivity='high'),
        DetectPII(),
        RedactSecrets(),
        LimitCost(max_total_tokens=100_000),
    ],
)

result = agent.run_sync('Plan a trip to Lisbon')
print(result.output)
```

Every guardrail is a `pydantic_ai.capabilities.AbstractCapability`. You add it with `Agent(capabilities=[...])`, the same way you add Pydantic AI's own capabilities. There is no wrapper class and no separate run method.

## Why this library

<CardGrid>
  <Card title="Pydantic AI native" icon="seti:python">
    Guardrails hook into the agent lifecycle (`before_run`, `prepare_tools`, `after_output_process`). Errors subclass Pydantic AI's `AgentRunError`.
  </Card>
  <Card title="18 built-in guardrails" icon="approve-check">
    PII, prompt injection, toxicity, keywords, length, rate limits, secrets, JSON, regex, refusals, hallucination heuristics, LLM judge, tool restrictions and token budgets.
  </Card>
  <Card title="Self-correcting output" icon="sync">
    Output guardrails raise `ModelRetry` by default, so the model sees the reason and rewrites its answer.
  </Card>
  <Card title="Traced with OpenTelemetry" icon="magnifier">
    Each check emits a `guardrail <Name>` span. With Logfire or any OTel SDK, guardrail spans nest inside the agent trace.
  </Card>
</CardGrid>

## Features

<CardGrid>
  <Card title="Input guardrails" icon="warning">
    Stop a run before the model is called. Raise `InputBlocked`, or log with `on_fail='warn'`.
  </Card>
  <Card title="Tool and cost guardrails" icon="setting">
    Allow, hide or approval-gate tools with glob patterns. Stop the run once a token budget is crossed.
  </Card>
  <Card title="Optional ML backends" icon="rocket">
    Regex detectors need no dependencies. Switch to Presidio, Detoxify or a transformers classifier with one argument.
  </Card>
  <Card title="Custom guardrails" icon="pencil">
    Pass any sync or async function to `InputGuardrail` or `OutputGuardrail`, or subclass a base class.
  </Card>
  <Card title="Config files" icon="document">
    Describe a guardrail set in JSON or YAML and build it with `build_guardrails(load_config(path))`.
  </Card>
  <Card title="Testing helpers" icon="puzzle">
    `pydantic_ai_guardrails.testing` provides async assertions built on Pydantic AI's `TestModel`.
  </Card>
</CardGrid>
