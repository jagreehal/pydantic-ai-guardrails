title: Built-in Guardrails
description: All 18 built-in guardrails at a glance
---

Every guardrail is a capability class. Import it from `pydantic_ai_guardrails` and add it to `Agent(capabilities=[...])`. Guardrails run in list order within each stage.

## Input

Run in `before_run`, before the model is called. Fail with `InputBlocked`, or log with `on_fail='warn'`.

| Guardrail | Blocks when |
|-----------|-------------|
| [DetectPII](../input/detect-pii/) | The prompt contains an email, phone, SSN, credit card or IP address |
| [DetectPromptInjection](../input/detect-prompt-injection/) | The prompt matches injection or jailbreak patterns |
| [DetectToxicity](../input/detect-toxicity/) | The prompt contains profanity, hate speech, threats or attacks |
| [BlockKeywords](../input/block-keywords/) | The prompt contains a blocked keyword |
| [LimitInputLength](../input/limit-input-length/) | The prompt exceeds a character or token budget |
| [RateLimit](../input/rate-limit/) | A key exceeds its request rate |

## Output

Run in `after_output_process`, for text and structured output. Default `on_fail='retry'` raises `ModelRetry`; `'raise'` raises `OutputBlocked`; `'warn'` logs.

| Guardrail | Fails when |
|-----------|------------|
| [LimitOutputLength](../output/limit-output-length/) | The output is outside character, word or sentence bounds |
| [RedactSecrets](../output/redact-secrets/) | Never fails: rewrites API keys and tokens to a placeholder |
| [ValidateJson](../output/validate-json/) | The output is not valid JSON or does not match a schema |
| [FilterToxicity](../output/filter-toxicity/) | The output contains toxic language |
| [DetectHallucination](../output/detect-hallucination/) | The output hedges or contains placeholder data |
| [MatchRegex](../output/match-regex/) | The output does not match the required patterns |
| [BlockRefusals](../output/block-refusals/) | The output is a canned refusal |
| [RequireToolUse](../output/require-tool-use/) | The run did not call the required tools |
| [LlmJudge](../output/llm-judge/) | A judge model scores the output below a threshold |
| [RequireGrounding](../output/require-grounding/) | The answer's claims aren't supported by the run's sources |

## Tool and cost

| Guardrail | Effect |
|-----------|--------|
| [RestrictTools](../tools/restrict-tools/) | Allowlists, hides or approval-gates tools (glob patterns supported) |
| [ValidateToolArgs](../tools/validate-tool-args/) | Rejects tool arguments that fail a check, so the model retries |
| [LimitCost](../cost/limit-cost/) | Stops the run with `BudgetExceeded` once token usage or dollar cost crosses a budget |

## Detection backends

The detectors default to regex, which has no dependencies and adds almost no latency. Three can switch to an ML backend:

| Guardrail | Backend | Extra |
|-----------|---------|-------|
| `DetectPII` | `backend='presidio'` | `pii-detection` |
| `DetectToxicity`, `FilterToxicity` | `backend='detoxify'` | `toxicity-detection` |
| `DetectPromptInjection` | `backend='transformers'` | `prompt-injection` |

Unknown option names (a PII type, toxicity category or secret pattern that does not exist) raise `ValueError` at construction.

## Custom guardrails

Need something else? [Write your own](../../guides/custom-guardrails/) with `InputGuardrail`, `OutputGuardrail`, `AsyncGuardrail`, or by subclassing `InputGuardrailBase` / `OutputGuardrailBase`.
